# Minimal 3D Game — Commit Test

یک بازی سه‌بعدی کاملاً مستقل و تازه، ساخته‌شده از صفر برای آزمایش:
MGit → Stage → Commit → Push → GitHub

- صحنه سه‌بعدی بسیار کوچک
- مکعب بازیکن و هدف
- زمین سه‌بعدی
- حرکت با W/A/S/D
- بدون تصویر، صدا یا Asset خارجی
- بدون `.git`
- هیچ فایل یا الگوی پروژه «کوهستان برفی ۱۹۴۲» استفاده نشده است.

این پروژه عمداً حداقلی است تا حجم انتقال اینترنت بسیار کم بماند.

نکته: حجم APK نهایی فقط به پروژه وابسته نیست و Godot و کتابخانه‌های Android نیز وارد APK می‌شوند؛ بنابراین زیر 10MB بودن APK را نمی‌توان صرفاً از روی پروژه تضمین کرد.
